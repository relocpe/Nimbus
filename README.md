# Nimbus

Меню-бар приложение для macOS, которое запускает обход DPI (для Discord и YouTube) одной кнопкой. Иконка-облако в строке меню, по клику открывается небольшая панель (HUD): включить и выключить сервис, выбрать стратегию, посмотреть логи.

Требования: macOS 14 или новее, сборка universal (Apple Silicon и Intel). Для запуска сервиса нужен пароль администратора.

Nimbus сделан **на основе** [Flowseal/zapret-mac-discord-youtube](https://github.com/Flowseal/zapret-mac-discord-youtube). Движок — [bol-van/zapret](https://github.com/bol-van/zapret) (`nfqws` через `utun` и BPF). Мы держим тот же рабочий пайплайн и пересобираем оболочку: свой UI, свои релизы, своё автообновление.

## Что умеет

- Облако в меню-баре и панель HUD, отдельного окна нет
- Запуск и остановка сервиса. Рядом две точки: доступны ли сейчас discord.com и youtube.com (проверка раз в несколько секунд, пока сервис запущен)
- Выбор стратегии из 21 готовой (из сборки Flowseal, GameFilter вырезан). По умолчанию `general-simple-fake`
- Пресет IPSet: нет / стандартный / все
- Тест стратегий прямо из панели (раздел «Ещё»): прогоняет стратегии и показывает результат по каждой, после теста возвращает прежние настройки
- Списки доменов и IP, которые можно править (раздел «Ещё» → «Списки»)
- Логи сервиса и кнопка «Копировать» (раздел «Ещё» → «Логи»)
- Автозапуск приложения при входе в систему
- Автообновление: приложение раз в час смотрит [релизы этого репозитория](https://github.com/samevamp/Nimbus/releases) и ставит новую версию из панели

Выход закрывает только приложение в строке меню. Сервис продолжает работать, пока не нажмёте **Остановить**.

## Установка

1. Выключите VPN с туннелированием.
2. Поставьте DNS не от провайдера — Google (`8.8.8.8`) или Cloudflare (`1.1.1.1`). Ещё лучше DNS over HTTPS, например [профиль Google Public DNS](https://github.com/paulmillr/encrypted-dns).
3. Скачайте `Nimbus-macOS-universal.zip` из [Releases](https://github.com/samevamp/Nimbus/releases).
4. Откройте приложение. Если Gatekeeper ругается: ПКМ → **Открыть**, либо **Системные настройки → Конфиденциальность и безопасность → Подтвердить вход**.
5. Клик по облаку → стратегия → **Запустить**.

## Списки

При первом запуске создаётся `~/Library/Application Support/ZapretMac/lists`.

- Свои домены: `list-general-user.txt` (поддомены подхватываются сами)
- Исключения доменов: `list-exclude-user.txt`
- Исключения IP: `ipset-exclude-user.txt`

Пресет:

- **Нет** — без дополнительного обхода по IP
- **Стандартный** — `ipset-all.txt`
- **Все** — IP-профили на весь IPv4, кроме исключений

После правки списка заново выберите стратегию или пресет, чтобы перезапустить сервис.

## Как это работает

Сервис ставится как системный LaunchDaemon (`io.github.flowseal.zapretmac`), поэтому при установке и запуске macOS просит пароль. Внутри работает `utunws`, сборка `nfqws` из bol-van/zapret под macOS: трафик заворачивается через интерфейс `utun` и правила `pf`, а выбранная стратегия (файл из `macos/Payload/strategies`) решает, как именно обходить DPI. Данные лежат в `~/Library/Application Support/ZapretMac` (выбранная стратегия, пресет, списки) и в `/Library/Application Support/ZapretMac` (установленная копия сервиса и логи `zapret.log`, `engine.log`).

## Сборка

Нужны Xcode или Command Line Tools: скрипт использует `swiftc`, `clang` и `make`.

```bash
git clone https://github.com/samevamp/Nimbus.git
cd Nimbus
./macos/build.sh
```

Приложение: `build/macos/Nimbus.app`, архив: `dist/Nimbus-macOS-universal.zip`. Сборка подписывается ad-hoc, без сертификата разработчика, поэтому Gatekeeper на другом Маке будет спрашивать подтверждение.

GitHub Actions (`.github/workflows/macos.yml`) собирает тот же universal-билд на каждый пуш. Релиз собирается workflow `release.yml` по тегу.

## Принудительная остановка

```bash
sudo "/Library/Application Support/ZapretMac/stop.sh"
```

## Проблемы

- **Сервис не запускается.** Откройте «Ещё» → «Логи»: там хвост `zapret.log` и `engine.log`. Если `utunws` не поднимает интерфейс `utun50`, установка сама останавливает сервис и пишет об этом. Сначала проверьте, что выключен VPN с туннелированием.
- **Точка Discord или YouTube красная при запущенном сервисе.** Попробуйте другую стратегию, для этого есть тест в «Ещё». Если DNS отдаёт провайдер, смените его (см. «Установка»).
- **Нет сети после сбоя.** Выполните команду из раздела «Принудительная остановка»: она убирает правила `pf` и останавливает процесс.
- **macOS не открывает приложение.** Подтвердите запуск, как описано в «Установке».
- **Приложение не обновилось.** Обновление ставится вручную кнопкой в «Ещё», когда в релизах появилась версия новее. Если загрузка не удалась, ошибку покажет само приложение.

Если ничего не помогло, заведите issue и приложите логи, предварительно убрав из них имя пользователя и другие личные данные.
